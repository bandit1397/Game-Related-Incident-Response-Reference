# 게임 관련 112신고 현장대응 매뉴얼

지구대·파출소 경찰관이 게임 관련 신고 현장에서 휴대폰으로 바로 찾아보는 매뉴얼입니다.

**장소 고르기 → 체크리스트 → 위반유형·적용법조 → 조치·통보**

## 구성

| 화면 | 내용 |
|---|---|
| 현장 핵심 | 홈 화면 요약 14줄 — 자주 나오는 행위 → 적용법조·처벌 |
| 장소 | PC방, 성인PC방, 청소년게임제공업소, 일반게임제공업소, 복합유통, 무허가 게임장, 슬롯머신, 식당 안 게임기, 보드게임카페, 홀덤펍, 스크린골프, 온라인 도박 |
| 상황 | 자주 나오는 신고 41가지와 판단 갈림길 |
| 주제 | 똑딱이(자동 누름 장치)·1인 여러 대 이용 — 업종별 적용표, 행정처분 기준 |
| 절차 | 접수~종결 흐름, 판정 사다리(손님/업주), 체포·압수 유의, 통보 기관, 112 종결 문안 |
| 법조 | 위반유형 50개를 형사처벌·과태료·행정처분별로 정리 |
| 사례 | 단속·판결 사례에 나온 게임명 |
| 즐겨찾기 | ☆로 모아 둔 장소·주제·상황·위반유형 |

## 사용 방법

- `index.html` 파일 하나로 동작합니다. 외부 서버나 라이브러리를 불러오지 않으므로 파일만 받아도 열립니다.
- GitHub Pages로 배포하면 링크로 공유하고 휴대폰 홈 화면에 추가할 수 있습니다.
- 홈 위쪽 검색창에 단어를 넣으면 주제·장소·상황·위반유형이 한 번에 검색됩니다(예: 똑딱이, 환전, 청소년 출입).
- 화면의 법조(예: `§28①6`, `형법 §246`)를 누르면 조문 원문이 아래에서 올라오고 해당 항·호가 강조됩니다. 원문이 파일에 들어 있어 인터넷 없이도 보입니다.
- 장소·주제·상황 화면 오른쪽 위 ☆, 위반유형 카드의 ☆ 버튼으로 **즐겨찾기** 탭에 모을 수 있습니다(이 휴대폰에만 저장).
- 체크리스트 표시는 화면을 닫으면 지워집니다(개인정보 미저장).

## 법령 기준

국가법령정보센터 현행 원문 대조, 확인일 2026-10-13.

- 게임산업진흥에 관한 법률(법률 제20485호, 시행 2025.10.23.), 시행령(별표2 개정 2026.2.3.), 시행규칙(별표5 행정처분 기준)
- 형법, 사행행위 등 규제 및 처벌 특례법, 국민체육진흥법, 관광진흥법, 청소년 보호법, 국민건강증진법

법령이 개정되면 `index.html` 상단의 데이터(`META`, `V`, `P`, `S`)를 고칩니다.

### 유지보수 시 주의: 즐겨찾기

상황 예시의 즐겨찾기는 번호 대신 **제목**으로 저장합니다. 상황 예시를 중간에 추가해도 즐겨찾기가 엉뚱한 항목을 가리키지 않게 하기 위해서입니다.
그래서 나중에 상황 예시의 **제목을 고치면**, 사용자가 그 상황을 즐겨찾기해 두었더라도 즐겨찾기 목록에서 빠집니다. 꼭 필요한 경우가 아니면 기존 상황 제목은 그대로 두는 것이 좋습니다.
